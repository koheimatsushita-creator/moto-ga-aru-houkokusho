# 見ていない架空の組（試験用）

case-06〜case-50 の45組。検査役への指示（lib/judge/prompt.ts）を作る時に一度も見ていない組で、検査役の判定の当たり外れを測るためだけに使う。画面（見本モード）には出さない。

- すべて架空。利用者の呼び名は「利用者A」〜「利用者E」だけ
- 正解（expected）は、開発に使ったClaudeが「先に種類を決めてから文を書く」作り方で付けた。看護の専門職は確認していない
- 判断の難しい文（言い換え⇔根拠なし、根拠なし⇔反する、離れた日の記録にだけ根拠がある文、数値の小さな食い違い、主語や情報源のすり替え）は、正解の reason の先頭に【境目】と付けた
- 検査役に通す前に正解を固め、その時点でコミットした（git の履歴で確かめられる）
- 形の点検：`npm run check:holdout`
